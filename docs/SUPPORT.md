# Suporte

## Como obter ajuda

1. Consulte a [documentação](../README.md) e os arquivos em `docs/`
2. Pesquise [issues existentes](https://github.com/venturalabs-ai/ventura.million/issues)
3. Abra uma issue com o modelo **Pergunta** ou **Relato de Bug**

## O que o projeto cobre

- Uso local do framework (agentes, skills, roteamento, exportação)
- Adaptadores e limitações documentadas de cada plataforma
- Problemas de instalação e validação

## O que não cobrimos

- Configuração de contas ou chaves de APIs de terceiros
- Suporte comercial de plataformas externas (Claude, ChatGPT, Grok, etc.)
- Problemas causados por uso de versões não oficiais ou forks não rastreados

## Segurança

Para vulnerabilidades, use o [Security Advisory](https://github.com/venturalabs-ai/ventura.million/security/advisories) — **não** abra issue pública.
